## GitHub About / project directory summary

Multi-Agent Workflow Lab is an experimental TypeScript framework for executing and testing agent delegation. It records parent/child tasks, context and permission decisions, tool and MCP calls, sandbox activity, resource use, evaluation findings, and replay evidence. The complete demo and test suite run locally with deterministic mock providers.

## Release announcement copy

Multi-Agent Workflow Lab v0.1.0 is available as an initial release candidate. It provides a typed multi-agent runtime, explicit delegation and policy evidence, controlled tool/MCP/sandbox boundaries, versioned prompts, deterministic evaluation, scenario testing, trace visualization, and guarded replay. Nine workflows and forty-four no-key tests demonstrate both successful behavior and blocked security failures.

These texts describe the local release candidate only. They do not imply production hardening, complete prompt-injection resistance, or remote deployment support.
