## [0.1.0] - 2026-08-12

### Added

- Typed multi-agent runtime, task graph, bounded scheduling, explicit delegation, loop prevention, cancellation, and result integration.
- Controlled tool pipeline with validation, permissions, contextual policy, approval, sandbox routing, redaction, timeout, and audit events.
- Official MCP stdio and Streamable HTTP client adapters plus deterministic in-memory connectors.
- Runtime-issued identities, local development authentication, deny-by-default permissions, context boundaries, secret references, and prompt provenance.
- Versioned and hash-protected prompt registry with strict processing and sixteen reusable prompt assets.
- JSON, YAML, Markdown, text, and structured-task parsers.
- In-memory, SQLite, and JSONL trace storage; task trees, Mermaid graphs, metrics, monitors, resource budgets, and cost estimates.
- Deterministic delegation evaluation, optional model judge, assertion DSL, YAML tests, scenario runner, seeded fault injection, run comparison, prompt regression, and guarded replay.
- Nine workflow examples, bad/good-orchestrator fixtures, eleven red-team prompts, and a no-key mock demo.
- Forty-four deterministic tests, including twenty dedicated security tests and the mandatory end-to-end execution chain.
